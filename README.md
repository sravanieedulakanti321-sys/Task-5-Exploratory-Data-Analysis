# Task 5: Exploratory Data Analysis (EDA)

## Objective
Explore a dataset using descriptive statistics and visualizations to identify patterns, trends, and possible anomalies.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Synthetic Employee Performance Dataset containing 200 records and 8 columns, including department, experience, salary, working hours, sales, performance rating, and employment status.

## Analysis Performed
- Data inspection using `info()` and `describe()`
- Missing-value analysis
- Histograms and count plots
- Scatterplots and boxplots
- Correlation heatmap and pairplot
- Summary of findings and business recommendations

## Files Included
- `Task_5_EDA.ipynb`
- `employee_performance_dataset.csv`
- `EDA_Findings_Report.pdf`
- `salary_distribution.png`
- `department_counts.png`
- `requirements.txt`

## Conclusion
EDA helps identify patterns, relationships, and unusual values in data. The analysis demonstrates basic data exploration and visualization techniques.

**Note:** The dataset is synthetic and intended for educational practice only.
